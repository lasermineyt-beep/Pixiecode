Create & Share Custom Questions

This guide explains how to build custom questions for each game type and how to share/open them on Pixiecode.

Before you start

  1. Open the Create Question page: create-question.html.
  2. Choose the Game Type at the top of the form.
  3. Fill the fields shown for the chosen game (Title/Question, Answer, Hint, Code/Lines).

1) Syntax Error (fill-the-blank)

  1. Select Syntax Error as Game Type.
  2. Enter the question text in Title / Question (for example: "int[] nums = _____ int[10];").
  3. Enter the correct token in Answer (e.g. new), and a short hint.
  4. Optional: paste a longer code snippet in the Code box — it will show inside the game.
  5. Click Generate Share Code to create a share string, or Open in Game to test now.

2) Syntax Savior (editable code)

  1. Select Syntax Savior.
  2. Paste the full initial code into the Code box (this becomes the editable starting file).
  3. Fill Answer with the expected solution token or snippet (used to validate success).
  4. Click Generate Share Code or Open in Game to play it right away.
  5. The game checks whether your edited code includes the provided solution string; include minimal expected text in Answer.

3) Drag & Drop (code lines)

  1. Select Drag & Drop.
  2. Enter the program lines in the Code box — one line per row in the correct final order.
  3. When players drag the lines into slots they are validated against those original positions.
  4. Click Generate Share Code to create a shareable string or Open in Game to test it now.

How sharing works

  1. Click Generate Share Code to produce a short string beginning with pixiecode:.
  2. Use the Copy button to copy that string to your clipboard.
  3. Send the string to others (chat, email, etc.).
  4. On the Pixiecode homepage, paste the string into the Open Shared Question input and click Open.
  5. The website stores the question temporarily and opens the target game; the game will load the custom question once and then clear the temporary storage.

Troubleshooting

  1. If the code says Invalid code, make sure you pasted the full generated string starting with pixiecode:.
  2. If a custom level doesn't appear in the game, refresh and try using Open in Game instead of pasting on the index.
  3. For large code blocks, ensure there are no stray control characters — paste as plain text.
